# ONG Esperança

Projeto acadêmico de uma plataforma web para uma organização não governamental.

## Objetivo

Desenvolver uma plataforma web responsiva para divulgar projetos sociais,
engajar voluntários, apresentar campanhas de arrecadação e disponibilizar
informações institucionais da ONG.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git e GitHub

## Estrutura

- index.html
- projetos.html
- cadastro.html
- voluntario.html
- admin.html
- script.js
- css/style.css

- HTTPS

- Banco de dados
- Autenticação segura

- Validação no servidor
- Proteção contra XSS
